# Video font

Videos use **Manrope Variable** from `@fontsource-variable/manrope`.

- License: SIL Open Font License 1.1
- Embedded subsets: Latin, Latin Extended, Cyrillic, Cyrillic Extended
- Weights: titles `700`, body text `500`

The font files are embedded into every render from the installed npm package,
so rendering does not depend on fonts installed in Windows or network access.
